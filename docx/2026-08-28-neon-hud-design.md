# 霓虹 HUD 风界面改造 · 设计文档

日期：2026-08-28
状态：[WIP]
范围：`panel/` 浮动卡片 + `dashboard/` 完整统计页

## 1. 目标与边界

将扩展的暗色主题升级为「霓虹 HUD 风」（参考 `img/1787805386.png`）：

- 深海军蓝玻璃底 + 全息网格背景
- 外圈青色描边光晕
- 主数字发光数码字重
- 霓虹渐变面积趋势图
- 命中率发光圆环进度图
- tokens/s 迷你柱状图
- 主按钮蓝→青渐变带外发光
- 成本金额琥珀金高亮

**不做**：亮色主题（月之亮面）保持不变；不引入任何第三方依赖；不改变数据采集与聚合逻辑。

## 2. 已确认决策

| 问题 | 结论 |
| --- | --- |
| 覆盖界面 | panel + dashboard 两个都改 |
| 与现有主题关系 | 直接替换暗色主题（亮 / 跟随系统保留；跟随系统在系统暗色时同样进入 HUD） |
| 图形化程度 | 全套：面积趋势图 + 命中率圆环 + tps 迷你柱状图 |
| 动效强度 | 适度：入场/生长动画，网格背景静态 |

## 3. 技术方案

CSS 变量换肤 + JS 生成内联 SVG 图形。零依赖，符合 MV3 CSP（扩展页面禁止远程脚本），与 panel 现有实现（`panel/panel.js:64` 的命中率圆环）同构。

备选（已否决）：Canvas 绘制（与 CSS 变量主题机制冲突）；本地打包 ECharts（体积与 CSP 代价过大）。

## 4. 主题机制

- `dashboard/dashboard.css` 与 `panel/panel.css` 中 `:root[data-theme="dark"]` 色板整体替换为 HUD 色板：
  - 底色：深海军蓝（约 `#060D1F` 系）
  - accent：青色（`#22D3EE` 系）
  - 成本色：琥珀金（`#FFC24B` 系）
  - 玻璃卡片：半透明白 3–6% + 背景 blur
- `@media (prefers-color-scheme: dark)` 下 `system` 分支与 `dark` 分支保持同一套 HUD 色板（维持现有结构，只改变量值）。
- 主题按钮「暗」的文案/提示更新为 HUD 语义（dashboard `data-theme-opt="dark"` 的 title，panel `#btn-theme` 的 title）。
- 装饰层（全息网格、顶部/底部径向光晕）复用 panel 已有写法（`--grid-line` + mask），dashboard 的 `body` 增加同构背景层。

## 5. panel 浮动卡片

现状已有雏形（玻璃底、网格、命中率圆环、token 渐变条、琥珀金成本）。本次补齐：

- 「平均 t/s」列：纯数字 → 数字 + 迷你柱状图（单行一根柱，按当前表格内最大值归一高度，青色渐变 + 顶部发光帽）。
- 主按钮「查看完整统计」：蓝→青线性渐变 + 外发光阴影。
- 发光强度、网格密度、边缘光晕对齐参考图观感。

## 6. dashboard 完整页

### 6.1 统计卡（6 张）

- 全部卡片玻璃拟态化 + 青色边缘光晕（hover 时增强）。
- 「总消耗」：主数字等宽数码字重（`font-variant-numeric: tabular-nums` + 字重提升）+ 青色 `text-shadow` 发光。
- 「缓存命中率」：数值旁加发光圆环（复用 panel 圆环的 SVG 结构与变量）。
- 「平均生成速度」：数值旁加迷你柱状图（近 N 天每日 tps 序列，N 跟随当前时间范围，上限 14 根）。
- 其余卡片仅皮肤变更，不加图形。

### 6.2 面积趋势图（新增）

- 位置：统计卡区下方、热力图上方，独立卡片。
- 数据：复用现有每日聚合序列（与热力图同源），随时间范围筛选联动。
- 形态：青→蓝渐变填充面积 + 发光描边线 + 末端光点；横轴日期稀疏刻度，纵轴不画（数值靠 hover/末端标签）。
- 退化规则：数据不足 2 个点时画单点光斑 + 基线；无数据时显示空态文案。

### 6.3 表格

- 模型表格「合计」列加 token 渐变条、「命中率」列加发光圆环（与 panel 组件写法一致）。
- 表头、行 hover、滚动条等细节换为 HUD 配色。

### 6.4 保留

- 每日消耗热力图保留在原位，仅配色换为 HUD 色板。

## 7. 动效（适度）

- 数字淡入（opacity/translateY，约 300ms）。
- 圆环 / 柱状图 / 面积图描边的生长动画（`stroke-dashoffset` 或 `transform` transition，约 400ms）。
- 网格背景静态，无扫描线、无呼吸。
- `prefers-reduced-motion: reduce` 时禁用全部动画。

## 8. 错误与边界

- 面积为 0 的日期画在基线上，不断线。
- 命中率无数据（分母为 0）时圆环显示空态（仅轨道、无进度弧），数字显示 `—`。
- tps 迷你柱状图数据为空时不渲染容器。
- 亮色主题下所有新增图形使用亮面色板变量，不出现 HUD 专属色。

## 9. 测试
